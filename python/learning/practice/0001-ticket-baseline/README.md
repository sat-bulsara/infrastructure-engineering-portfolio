# Practice 0001: Ticket baseline

## Outcome

Represent one fictional support ticket with four variables and print a readable
three-line summary.

## Task

1. Open `ticket_baseline.py`.
2. Replace the four `TODO` values. Keep the data fictional.
3. Before running it, write down the three lines you expect.
4. Run:

```bash
python3 ticket_baseline.py
```

5. Paste the exact output into the Python tutor.
6. Explain which value is a string, which is an integer and which is a Boolean.

Do not add input or conditions yet. The first step is about values, names and
formatted output.
