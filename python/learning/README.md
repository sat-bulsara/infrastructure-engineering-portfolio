# Python Infrastructure Tutor

This folder is the portable source of truth for a stateful, project-based Python
tutor. It teaches Python from the foundations through practical infrastructure
automation without rushing into complex libraries before the language makes
sense.

The curriculum contains 24 coding projects. Every project ends with a practical
quiz, and every four projects end with a cumulative phase gate and mini-build.

## Continue on any machine

1. Clone or pull the portfolio repository.
2. Open Codex in the repository.
3. Ask: `Continue my Python learning from the Python tutor.`
4. Codex reads the repository guidance and the saved state in this folder.
