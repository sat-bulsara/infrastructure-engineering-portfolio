# Python Learning Mission

## Topic

Python for infrastructure engineering, IT support and automation.

## Why this matters

Build genuine coding confidence for infrastructure work. Python should become a
tool Sat can use to remove repetitive support work, inspect data, integrate with
systems and create reliable operational utilities, rather than a collection of
syntax remembered only inside exercises.

## Real-world outcome

Design, build, test, troubleshoot and explain useful Python command-line tools
for infrastructure and IT operations.

## Constraints

- There is no artificial deadline. Confidence and evidence matter more than pace.
- Keep one concept and one small coding action active at a time.
- Sat has basic Python and JavaScript exposure, but independent Python fluency
  has not yet been established in this course.
- Some practice will happen on a laptop while travelling and should work offline.
- Use fictional or sanitised data and authorised lab systems.
- Avoid live production changes, exposed secrets and unnecessary dependencies.
- Use UK English, direct wording and no em dashes.

## Completion evidence

- [ ] Complete Projects 01-24 progressively with tested evidence and quizzes.
- [ ] Build small programs from a stated outcome without exact steps.
- [ ] Explain values, control flow, collections, functions, files, exceptions,
      modules, tests and command-line interfaces in Sat's own words.
- [ ] Diagnose tracebacks and failing tests using evidence rather than guessing.
- [ ] Use virtual environments, logging, typing and dependencies appropriately.
- [ ] Build a safe infrastructure operations CLI with documentation and tests.
- [ ] Reuse Python inside a later Linux or Azure project with little or no help.
- [ ] Repair every missed project and phase-gate quiz item through changed code,
      not by memorising an answer key.
