# Project 01: Service Desk Ticket Triage

## Operational problem

Support tickets can be recorded inconsistently, which makes priorities harder to
compare and handovers harder to scan. This learning project will turn fictional
ticket details into a small, consistent command-line summary.

## Outcome

Build a Python program that collects fictional ticket details, validates them,
assigns a priority using documented rules and prints a clear summary.

## Progressive build

1. Represent one static ticket with variables and output.
2. Collect values with `input()`.
3. Normalise text before comparing it.
4. Apply impact and urgency rules with conditions.
5. Move the rule into a function.
6. Reject unsupported input clearly.
7. Add tests for normal and boundary cases.
8. Complete a changed ticket scenario without procedural steps.
9. Complete the Project 01 no-notes quiz and repair every missed item.

## Safety and scope

- Use fictional tickets only.
- Do not connect to a real ticketing platform in this project.
- Do not include names, email addresses or employer data in Git.

## Completion evidence

- [ ] Working command-line program
- [ ] At least four documented priority examples
- [ ] Invalid input handled clearly
- [ ] Automated tests passing
- [ ] One deliberately failing test diagnosed and repaired
- [ ] Sat explains the rule and code structure without notes
- [ ] Project quiz completed, missed items repaired and coding check rerun
