# Project 01 Working Instructions

This lab establishes a safe, repeatable Linux baseline before later projects
make administrative changes.

## Environment

- Disposable Ubuntu Server ARM64 virtual machine
- VMware NAT networking
- Standard user with controlled `sudo` access
- SSH access from WezTerm

Do not record passwords, private keys, raw usernames, hostnames or IP addresses
in this repository.

## Current build sequence

1. Identify the distribution and release.
2. Confirm the current user and privilege boundary.
3. Distinguish the filesystem root, home and working directory.
4. Inspect kernel, architecture, CPU, memory and storage.
5. Use local command help.
6. Create a sanitised baseline report.
7. Build and explain a small Bash baseline script.
8. Repeat on a changed lab with less support.
9. Complete the practical exit quiz and repair missed items.

The live checkpoint and single next action are stored in
[`../../learning/PROGRESS.md`](../../learning/PROGRESS.md).
