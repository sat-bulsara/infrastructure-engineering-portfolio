# Linux

This section develops Linux administration, troubleshooting, security and
automation through progressively independent projects. It begins with safe host
context and filesystem work, then moves through permissions, services, packages,
networking, storage, logs, SSH, Bash and incident recovery.

The tutor uses 24 progressively harder coding projects, repeated Bash skills,
controlled break/fix, project quizzes and cumulative phase gates.
