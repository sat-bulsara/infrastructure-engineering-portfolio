# Practice 0001: Environment baseline

## Outcome

Prove which Linux distribution and release you are administering before any
system changes.

## Current task

On the intended Linux lab, run:

```bash
cat /etc/os-release
```

Paste the exact output into the Linux tutor. Do not redact ordinary distribution
names or version information, but do not include unrelated terminal history,
public IP addresses, usernames or hostnames.

If `/etc/os-release` does not exist, stop and share the error. If you do not yet
have a Linux lab, say so and the tutor will guide a safe lab setup before the
course continues.

## Explain after the run

Be ready to answer:

- What evidence proves this is Linux rather than macOS?
- Which line identifies the distribution?
- Which line identifies the release?
