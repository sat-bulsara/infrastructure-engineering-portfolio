# Linux and Bash Repetition System

The course uses a spiral rather than teaching each command or Bash construct
once.

| Pass | Timing | Support | Evidence |
| --- | --- | --- | --- |
| Learn | Current project | Guided or Partial | First safe use and explanation |
| Immediate variation | Same or next project | Hint | Changed path, user, data or requirement |
| Interleaved recall | Two to four projects later | Hint or None | Correct command or code selected without a reminder |
| Phase gate | Every fourth project | None before attempt | Cumulative quiz and mini-script |
| Delayed transfer | Later phase | None | Skill reused on another component or host |
| Capstone | Project 24 | None | Independent diagnosis, coding, recovery and explanation |

For every project after Project 02, the brief names at least two earlier Linux
or Bash skills to reuse. One must use less support than before. Repeating an
identical pasted command does not count as another fluency pass.

If recall fails, return to a small changed mini-lab, then recheck with a new
path, service, host or dataset. Do not rebuild the whole project unless the
underlying mental model is missing.
