# Linux Infrastructure Tutor

This folder is the portable source of truth for a stateful, project-based Linux
tutor. It teaches Linux from safe terminal foundations through administration,
security, troubleshooting, Bash automation and incident recovery.

The curriculum contains 24 coding projects. Every project produces Bash or,
later, justified Python code. Every project ends with a practical quiz, and every
four projects end with a cumulative phase gate and mini-script.

## Continue on any machine

1. Clone or pull the portfolio repository.
2. Open Codex in the repository.
3. Ask: `Continue my Linux learning from the Linux tutor.`
4. Codex reads the repository guidance and the saved state in this folder.
