# Projects

Complete the numbered folders in order. Each `starter.ps1` intentionally contains TODOs and is expected to be incomplete.

Do not store finished code in the starter file. Copy it to a clearly named script such as `Get-SystemInventory.ps1`, then add your documentation and sample output to the same project folder.

The complete learning design and current state live in
[../learning](../learning/README.md). Project folders after 08 are created when
their prerequisite phase becomes current.
