# PowerShell Infrastructure Tutor

This is the persistent teaching workspace for the 24-project PowerShell course.
It teaches PowerShell coding through Windows, Active Directory, Azure and
Microsoft 365 infrastructure outcomes.

## Start or continue

1. Open [PROGRESS.md](PROGRESS.md).
2. Complete only the recorded next action.
3. Run the exact script in PowerShell.
4. Send the tutor your code and exact output.
5. Let the tutor record the evidence and next action.
