# PowerShell Learning Mission

## Topic

PowerShell for infrastructure support, Windows administration, Active Directory,
Azure and Microsoft 365 automation.

## Why this matters

Sat wants to move beyond following commands and become able to design, write,
test and troubleshoot useful automation. The course should support his Windows
and Azure portfolio while building transferable coding ability.

## Real-world outcome

Given an unfamiliar support or infrastructure task, Sat can discover the right
commands, reason about the objects they return, write a safe reusable tool,
verify its behaviour, diagnose failures and explain the design without copying a
finished solution.

## Constraints

- Learning is step by step and project based.
- Sessions may happen offline on a spare Windows laptop while travelling.
- Practice should use editable `.ps1` files rather than long HTML lessons.
- New syntax should be compared with Python or JavaScript when helpful.
- Every new concept should include a focused official research link.
- Privileged work must stay inside authorised disposable labs.
- Cloud projects require an authorised practice tenant.
- Credentials, tokens, tenant identifiers and private data must not enter Git.

## Completion evidence

- [ ] Complete Projects 01-24 with executable PowerShell code.
- [ ] Complete and repair every project exit quiz.
- [ ] Pass six cumulative phase gates with independent coding and break/fix work.
- [ ] Build a tested administration module using Pester and PSScriptAnalyzer.
- [ ] Automate a safe Windows or identity workflow in a disposable lab.
- [ ] Automate an Azure or Microsoft 365 reporting workflow in a practice tenant.
- [ ] Complete the final unseen infrastructure automation assessment.
