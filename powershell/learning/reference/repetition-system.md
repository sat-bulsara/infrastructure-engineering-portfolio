# PowerShell Repetition System

The course revisits important skills with less support and changed surface
details. Repetition means retrieving and adapting, not rerunning an unchanged
finished script.

## Five passes

| Pass | Tutor support | Learner work | Evidence |
| --- | --- | --- | --- |
| Guided | Full or Partial | Predict, write one section, run and explain | Correct result with the new idea understood |
| Variation | Hint | Change data, parameter or requirement | Adapted code without copying the first answer |
| Independent | None | Build from a short outcome | Working code and separate verification |
| Break/fix | Symptoms only | Form a hypothesis and repair | Error, cause, repair and retest explained |
| Transfer | None | Reuse the skill in a later project | Correct selection and adaptation of the skill |

## Retrieval timing

Schedule important skills:

- near the next session;
- about one week later;
- about one month later;
- whenever a later project depends on them.

Adjust the timing from demonstrated recall. A missed item returns sooner and is
tested with different wording, values or system context.

## Support reduction

Record help as:

- None: independently selected and implemented;
- Hint: concept or direction only;
- Partial: structure supplied but key logic written by Sat;
- Full: complete line or solution supplied.

A skill moves toward fluency only when Sat later completes a changed task with
less support.
