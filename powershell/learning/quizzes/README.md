# Project Exit Quizzes

Every numbered project ends with a no-notes six-part quiz. The quiz checks
whether Sat can reason and code, not whether he can recognise a copied answer.

## Six required parts

1. Explain the project's central PowerShell mental model.
2. Predict object, pipeline or script output.
3. Diagnose a short error or bug.
4. Write a small PowerShell fragment from a requirement.
5. Make and justify a security, privilege, scope or rollback decision.
6. Transfer the skill to different data, a different command or another lab.

## Review rules

- Present one item at a time.
- Do not include an answer key in an unattempted quiz.
- Record the exact answer and help level.
- A missed item creates a changed mini-lab.
- Ask a different version after the repair.
- Do not treat a percentage score as proof of mastery.

## Phase gates

Projects 04, 08, 12, 16, 20 and 24 are followed by cumulative phase gates.
Each gate includes retrieval, a break/fix task and a small tool built from
requirements without copying an earlier script.
