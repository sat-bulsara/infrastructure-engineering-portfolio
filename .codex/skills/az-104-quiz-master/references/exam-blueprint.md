# AZ-104 exam blueprint

Source: [Microsoft AZ-104 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104)

Snapshot checked: 13 September 2026. The page states skills measured as of 17 April 2026.

| Domain | Weight |
|---|---:|
| Manage Azure identities and governance | 20-25% |
| Implement and manage storage | 15-20% |
| Deploy and manage Azure compute resources | 20-25% |
| Implement and manage virtual networking | 15-20% |
| Monitor and maintain Azure resources | 10-15% |

## Objective families

- Identities and governance: Entra users and groups, licences, external users, SSPR, RBAC, scope, management groups, subscriptions, resource groups, Policy, tags, locks, budgets and costs.
- Storage: accounts, redundancy, access control, SAS, firewalls, endpoints, Blob lifecycle and protection, Azure Files and File Sync.
- Compute: ARM and Bicep, VMs, disks, availability, scale sets, Bastion, ACR, ACI, App Service, slots, TLS and backups.
- Networking: VNets, subnets, addressing, peering, routes, NSGs, ASGs, DNS, load balancing and Network Watcher.
- Monitoring and maintenance: Azure Monitor, logs, alerts, action groups, Log Analytics, KQL, insights, diagnostic settings, Backup, Site Recovery, updates and service health.

Consult the live study guide before a full mock or readiness audit.
