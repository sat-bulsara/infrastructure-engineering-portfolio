# Portable AZ-104 Quiz Master

This folder stores Sat's adaptive quiz progress. Tutor behaviour lives in `/.codex/skills/az-104-quiz-master/`. Both folders travel in this Git repository.

## Use on another machine

1. Clone or pull this repository.
2. Open the repository root in Codex.
3. Confirm `.codex/skills/az-104-quiz-master/SKILL.md` exists.
4. Ask: `Use $az-104-quiz-master and continue my AZ-104 practice.`
5. Commit and push changed quiz records after a session to synchronise another machine.

Do not copy only this state folder because the repository-local skill contains the tutor instructions.

- PROFILE.md stores stable learning preferences.
- PROGRESS.md stores domain and readiness status.
- SESSION.md stores the exact resume point.
- RESULTS.csv stores question-level evidence.
