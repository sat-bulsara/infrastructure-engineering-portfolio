## Changed Scenario

condition such as resource type, scope, name, access path, failure, or tool.

## Retrieval First

Without notes, explain one idea needed for this task.

## Focused Source

Link one current official source and state the exact question it should answer.

## Safety and Cost Check

- Confirm the active tenant and subscription without recording identifiers.
- Confirm permission and least-privilege scope.
- Identify public exposure, secret handling, likely cost, and cleanup.
- Stop before any destructive, chargeable, tenant-wide, or lockout-prone action
  that has not been deliberately approved.

## Task

Give one clear goal and observable success criteria. For R3 and later, do not add
a procedural recipe.

## Layered Hints

Keep these collapsed or provide them one at a time:

1. Hint: point to the concept or diagnostic boundary.
2. Partial: name the relevant service, command family, or setting.
3. Full: show a safe example only when needed, then require a fresh variation or
   explanation.

## Verify

Require read-only evidence and state the expected healthy result.

## Break/Fix

For R4, provide symptoms without revealing the cause. Require:

1. Initial hypothesis
2. Evidence collected
3. Root cause
4. Repair
5. Retest

## Explain and Transfer

- Explain why the result worked in the learner's own words.
- State where the same skill appears in a later project or another tool.
