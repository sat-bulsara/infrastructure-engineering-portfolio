# Azure Learning Mission

## Topic

Microsoft Azure administration, cloud engineering, automation, security, and
AZ-104-level operational capability.

## Why This Matters

Build genuine confidence with Azure and cloud infrastructure for infrastructure
engineering work. Certification should follow demonstrated capability rather than
becoming a race to memorise an exam.

## Real-World Outcome

Design, deploy, secure, automate, monitor, troubleshoot, recover, explain, and
document a small Azure environment using appropriate Azure services and tools.

## Learning Approach

- Start with real projects and teach only the prerequisite needed for the next task.
- Use focused current Microsoft documentation when a project needs authoritative guidance.
- Practise one small concept before combining it into a larger project.
- Build manually before automating.
- Verify healthy state, introduce controlled faults, diagnose, repair, and retest.
- Use Timothy Warner's completed labs for useful extra repetitions.
- Introduce PowerShell, Azure CLI, Bicep, Terraform, and Python progressively.
- Complete the full Microsoft Learn paths and Applied Skills after the projects to consolidate terminology and expose gaps.
- Repeat important skills through short changed mini-labs with progressively less help.
- Interleave earlier skills into later projects until they can be explained, performed, verified, and troubleshot independently.

## Constraints

- No fixed exam date or artificial deadline.
- Avoid cognitive overload by keeping one concept and one task active at a time.
- Some work may be completed on a separate Windows machine or while travelling.
- Azure cost, licensing, tenant permissions, and regional availability may limit
  which features can be deployed.
- Use only disposable, authorised lab resources.
- Keep all repository evidence public-safe and free from secrets and identifiers.

## Completion Evidence

- [ ] Complete Builds 11-22 in the progressive Azure roadmap with verification.
- [ ] Explain the major cloud and Azure design decisions in the learner's own words.
- [ ] Rebuild and repair core services without exact step-by-step instructions.
- [ ] Demonstrate useful PowerShell, Azure CLI, Bicep, Terraform, and Python work.
- [ ] Complete an integrated capstone with security, monitoring, recovery, cost,
      troubleshooting, and cleanup evidence.
- [ ] Reach the AZ-104 readiness gate only when confidence and evidence support it.
- [ ] Complete the numbered portfolio projects progressively after the core is stable.
- [ ] Complete post-project Microsoft Learn consolidation and repair any gaps it exposes.
- [ ] Demonstrate delayed recall and independent transfer of important skills in changed scenarios.
