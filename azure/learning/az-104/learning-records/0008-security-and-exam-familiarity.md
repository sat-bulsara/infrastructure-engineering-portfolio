# Learning Record 0008: Security and Exam Familiarity

## Date

2026-08-23

## Change

The chronological Azure roadmap now runs from Project 11 to Project 38. It adds
dedicated Defender for Cloud and Microsoft Sentinel projects, followed by an
independent Azure Administrator Scenario Challenge before the first capstone.

Every roadmap entry now includes an estimated completion range. The range
includes focused study, implementation, command-line repetition, verification,
break/fix work, evidence capture and an initial documentation pass.

## Reason

Sat wants the official AZ-104 practice assessment to feel like a review of work
already performed. The roadmap therefore repeats identity and governance,
storage, compute, networking, monitoring and recovery across later projects
instead of relying on one pass through each service.

Security is also treated as a continuous engineering concern. Dedicated posture
and investigation projects sit alongside the existing Policy, RBAC, private
networking, WAF, Zero Trust, Key Vault and secure-delivery work.

## Evidence boundary

This is a planning change only. It does not demonstrate Defender for Cloud,
Sentinel or AZ-104 exam readiness.
