# Azure mission changed from exam schedule to mastery path

- Date: 2026-08-08
- Status: Active
- Context: The original roadmap attempted to fit core Azure, AZ-104, Terraform,
  Python, multiple Applied Skills, and advanced portfolio projects into eight
  weeks.
- Evidence: The learner explicitly stated that there is no rush to sit the exam
  and that the priority is understanding Azure and cloud without becoming
  overwhelmed.
- Learning: AZ-104 will be used as a structured coverage map and confidence
  checkpoint. Microsoft Learn provides the official teaching spine, Timothy
  Warner provides supplementary guided labs, personal projects provide evidence,
  and automation is introduced after the service is understood.
- Revisit when: An exam date is chosen, the learning mission changes, or the core
  capstone is complete.
