# Learning Record 0007: Chronological Project Roadmap

## Date

2026-08-23

## Change

The Azure roadmap was reorganised into one chronological sequence from Project
11 to Project 35. Embedded applied projects and lettered extensions were removed
as separate categories and their useful outcomes were merged into numbered
projects.

## Reason

The earlier structure made it difficult to see the true order and overall
progress. Sat prefers a visible numbered journey and wants enough purposeful
repetition to become fluent rather than rush through a short list.

## Additions

- More networking depth through private connectivity, application delivery,
  hub-and-spoke routing, Azure Firewall, hybrid VPN and DNS projects.
- A dedicated Linux VM and Bash administration project.
- Separate Bicep and Terraform foundations projects.
- Three capstones that progress from core Azure administration to a secure cloud
  platform and then hybrid incident recovery.

## Evidence boundary

This is a curriculum and planning change. It is not evidence that any newly
listed Azure skill has been demonstrated.
