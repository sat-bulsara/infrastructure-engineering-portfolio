The five assessed areas

APL-1008 evaluates domain controllers, topology, directory objects, Group Policy, and AD DS security. The assessment is a hands-on lab, so recognising a term is not enough. You need to produce the required state and verify it.

discover -> scope -> snapshot -> change -> verify -> explain -> record

Safety gate

Use a disposable environment

Do not practise risky AD changes in a live organisation. Confirm an authorised lab and a recoverable snapshot.
