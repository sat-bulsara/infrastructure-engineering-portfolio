Group Policy and password policies

Predict the winning policy, configure narrow scope, and prove the endpoint result.

Outcome

You can create, link, configure, scope, order, and verify policy.

Official module: 3 of 5

Retrieve first

Predict before opening GPMC

Compact model

A GPO can exist without applying. A link supplies scope. Object placement, enabled sections, security filtering, inheritance, enforcement, and link order help determine effective policy. The GPMC report proves configuration; RSoP or gpresult proves the endpoint result.

gpupdate /force
gpresult /h C:\Temp\gpresult.html

Worked reasoning

Password policy has two routes

The default domain password policy supplies the domain baseline. A fine-grained password policy targets users or global security groups. Query the actual user's resultant password policy rather than assuming the lowest-looking number won.

Mini quiz

Module 3 check

1. Expand LSDOU in order.

2. What connects a GPO to a site, domain, or OU?

3. Name a tool that proves effective policy on a target.

4. Which policy type can give a group a stricter password policy?

5. When multiple PSOs apply directly or through groups, which precedence number has priority?

Answer explanations
  1. Local, Site, Domain, OU.
  2. A GPO link supplies directory scope.
  3. `gpresult` and RSoP show effective policy.
  4. A fine-grained password policy targets selected users or groups.
  5. The lowest precedence number wins after normal applicability rules.
