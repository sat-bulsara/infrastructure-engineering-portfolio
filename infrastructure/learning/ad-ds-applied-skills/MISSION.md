# Learning Mission

## Topic

APL-1008: Administer Active Directory Domain Services companion

## Why this matters

Build practical AD DS administration capability for Sat's progression from IT
support into Microsoft infrastructure engineering. The goal is confidence with
the technology and the assessment lab, not memorising an answer sequence.

## Real-world outcome

Complete the official Microsoft Learn path and guided project, demonstrate
every operation in the APL-1008 study guide inside a disposable Windows Server
lab, and pass a 45-minute independent mock assessment before attempting the
Microsoft Applied Skills assessment.

## Constraints

- Microsoft Learn remains the source for the official modules and guided labs.
- The local course is a companion and must not copy Microsoft's full content.
- Lessons and state must work offline after the official pages have been read.
- Keep most companion sessions to one focused outcome lasting 10 to 30 minutes.
- Use a disposable AD DS lab with snapshots for administrative and destructive
  exercises.
- Never store passwords, DSRM credentials, tokens, private keys, or real
  organisational data in Git.
- Sat attempts the task before receiving a complete procedure.
- Use normal ASCII hyphens in paths and documentation.

## Completion evidence

- [ ] Complete all five Microsoft Learn modules and their module assessments.
- [ ] Complete the five official guided-project lab pages in order.
- [ ] Demonstrate the 22 study-guide operations in the disposable lab.
- [ ] Explain the purpose, risk, verification, and rollback boundary for each
  assessed skill area.
- [ ] Complete at least one delayed retrieval pass for every skill area.
- [ ] Pass the local 45-minute mock with at least 13 of 15 tasks independently
  and no critical safety failure.
- [ ] Review weak areas and repeat a fresh variation before launching the real
  assessment.
