# APL-1008 Active Directory Domain Services Companion

This portable companion supports Microsoft's **Administer Active Directory
Domain Services** Applied Skill.

Microsoft Learn remains the official teaching and guided-project surface. This
workspace adds:

- readiness checks;
- short retrieval and PowerShell drills;
- safe lab preparation and rollback gates;
- evidence and explanation prompts;
- spaced repetition with changed scenarios;
- a 45-minute, 15-task local mock assessment.

## Start

Open [`index.html`](index.html) in a browser, then follow the current action in
[`PROGRESS.md`](PROGRESS.md).

The first activity is
[`Lesson 0001: Start here and readiness baseline`](lessons/0001-start-here-and-readiness-baseline.html).

Use the [`full offline study guide`](reference/full-study-guide.md) during
learning and the first rehearsal. Every companion lesson ends with a
five-question mini quiz. Use the final local mock without the guide so that it
tests recall and administration under time pressure.

## Portability

All course state, lessons, references, and assessments use relative links and
local assets. Commit the workspace to Git and clone it on another machine to
continue with a new Codex task.

Browser checkboxes and text fields use local browser storage for convenience.
Canonical progress remains in the Markdown state files.

## Important boundary

Use only a disposable, authorised AD DS environment. Never commit passwords or
the credentials printed on Microsoft's guided-lab pages. The local mock is an
original practice scenario and does not reproduce Microsoft's private
assessment.

Microsoft's current candidate agreement prohibits AI assistance during the
real assessment. Do not use Codex, disclose assessment tasks, or assume an
external reference is permitted. Follow the instructions displayed in the
assessment lab.
