# Assessment Blueprint

This maps the public APL-1008 operations to local teaching and evidence. It does
not contain private Microsoft assessment tasks.

| Public operation | Lesson | Independent evidence |
| --- | --- | --- |
| Deploy a DC | 0002 | Promotion plus DC, DNS, SYSVOL, and replication health |
| Transfer FSMO | 0002 | Owner before and after |
| Raise functional levels | 0002 | Compatibility decision and final modes |
| Create site and subnet | 0002 | Site and subnet mapping |
| Move DC between sites | 0002 | DC placement and replication health |
| Create user | 0003 | Attributes, OU, and enabled state |
| Bulk-manage users | 0003 | Per-row result and safe rerun |
| Manage disabled users | 0003 | Before and after state |
| Reset passwords | 0003 | Account state without password exposure |
| Implement gMSA | 0003 | Retrieval scope and successful host test |
| Create groups | 0003 | Scope, category, and membership |
| Manage privileged membership | 0003 | Protected Users membership and rollback |
| Manage OUs | 0003 | Structure and accidental-deletion boundary |
| Recover deleted objects | 0003 | Original location and attributes restored |
| Create and link GPO | 0004 | GPO inventory and link |
| Configure GPO settings | 0004 | GPO report and endpoint result |
| Configure scope and order | 0004 | Prediction and RSoP comparison |
| Domain password policy | 0004 | Independent default-policy query |
| Fine-grained password policy | 0004 | Resultant PSO for target user |
| Delegate AD permissions | 0005 | Positive and negative tests |
| Configure auditing | 0005 | Effective policy and labelled event |
| Configure user rights | 0005 | Effective policy plus allowed and denied tests |

The coverage checklist contains 22 rows because the public study-guide wording
separates some closely related operations. The timed mock groups them into 15
scenario tasks, consistent with Microsoft's published typical range of 12 to
16 tasks.
