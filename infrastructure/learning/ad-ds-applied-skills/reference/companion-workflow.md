# Companion Workflow

## Before an official unit

1. Open the matching companion lesson.
2. Complete retrieval without notes.
3. Predict the purpose, risk, and verification of the upcoming task.

## During the official unit

1. Read the Microsoft content in order.
2. Pause after each mini section and recall three facts.
3. Complete Microsoft's own knowledge check honestly.
4. Record uncertain concepts, not copied paragraphs.

## After the official unit

1. Complete the companion's five-question mini quiz.
2. Perform the short learner task in a disposable lab.
3. Record evidence and help used.
4. Repeat a changed variation later before marking Independent.

## If stuck

1. State the expected result and exact observed result.
2. Recheck target, DNS, time, scope, and permissions.
3. Open Hint 1 only.
4. If still stuck, open Hint 2.
5. Read the linked official source before asking for a complete procedure.
