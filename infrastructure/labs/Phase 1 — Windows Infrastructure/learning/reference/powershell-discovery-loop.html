The loop

Five questions

  1. What commands exist?
  2. What syntax and examples are documented?
  3. What does the safe read command return?
  4. Which properties contain the evidence I need?
  5. How will I verify a later change independently?

Find commands

Get-Command -Name "Get-Process"
Get-Command -Name "*NetIP*"
Get-Command -Verb Get -Noun "*Service*"

Read help

Get-Help -Name Get-Process
Get-Help -Name Get-Process -Examples
Get-Help -Name Get-Process -Parameter Name
Get-Command -Name Get-Process -Syntax

Inspect returned objects

$result = Get-Process | Select-Object -First 1
$result | Get-Member
$result.PSObject.TypeNames

Properties contain data. Methods perform actions.

Select evidence

$result | Select-Object -Property Name, Id, CPU

Selecting properties produces focused structured output that can be filtered, exported, tested, or added to a report.

Administrator rule

Read before write

Start with discovery and read-only inspection. Before running a configuration command, know:

  • the exact target object;
  • the parameters and values;
  • whether -WhatIf is supported;
  • the expected result;
  • the separate command that will verify it;
  • how to recover in the disposable lab.

This page works offline. Check current Microsoft documentation before using unfamiliar administrative commands.
