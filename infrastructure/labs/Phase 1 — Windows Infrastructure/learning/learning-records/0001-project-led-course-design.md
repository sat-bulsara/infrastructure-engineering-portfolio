# Project-led course design

- Date: 2026-07-28
- Status: Active
- Context: Sat wants PowerShell taught in the order it is required by the infrastructure portfolio rather than as an isolated language syllabus.
- Evidence: The Phase 1 Notion plan and local Build 02 documentation were inspected and mapped to PowerShell outcomes.
