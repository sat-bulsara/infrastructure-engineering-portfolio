How it works

Learn it when the project needs it

Each build introduces only the PowerShell required for its real infrastructure outcome. You will retrieve earlier syntax, learn one new concept, complete a safe drill, apply it in the lab, verify the result, and then troubleshoot a controlled fault.

What counts as progress?

Reading a lesson is not enough. Progress is recorded when you retrieve an idea, write or run a command, explain its output, verify a result, or diagnose a controlled failure. The canonical record stays in PROGRESS.md so another Codex task can continue from the same point.
