# Learning Mission

## Topic

Phase 1 — Windows Infrastructure

## Why this matters

Build the practical Windows administration and PowerShell capability needed to progress from IT support into Microsoft infrastructure engineering.

## Real-world outcome

Build, automate, troubleshoot, and explain a functional Windows Active Directory environment from scratch.

## Constraints

- Lessons must work offline on a spare laptop while travelling.
- Keep most sessions to one focused outcome that can be completed in 10–30 minutes.
- Use a disposable lab for administrative and destructive exercises.
- Teach PowerShell just in time for the current infrastructure project.
- Sat writes the exercise code; Codex reviews and guides.

## Completion evidence

- [ ] Install and configure Windows Server.
- [ ] Deploy an Active Directory forest and domain.
- [ ] Build and explain an OU, user, group, and computer-account structure.
- [ ] Join a Windows client and authenticate a domain user.
- [ ] Automate core server and Active Directory administration with PowerShell.
- [ ] Diagnose and recover from planned networking, DNS, identity, and domain-join faults.
- [ ] Rebuild the Phase 1 environment without step-by-step notes.
- [ ] Publish the scripts, evidence, diagrams, and lessons learned to GitHub.
