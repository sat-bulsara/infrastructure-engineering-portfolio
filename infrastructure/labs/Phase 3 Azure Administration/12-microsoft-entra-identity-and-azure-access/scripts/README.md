# Scripts

No standalone automation script was created for this lab. The identity and RBAC
workflow was first completed in the portal, then selected operations were
performed and verified interactively with Azure CLI and Azure PowerShell.

The commands actually used are retained in the
[code snippets sheet](../reference/code-snippets.md). A later repetition can
turn the verified workflow into a parameterised script with validation,
idempotent behaviour and post-change checks.
